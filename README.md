# PixelForge Studio

A modern and creative digital agency website designed to help businesses grow online.

## 🌐 Live Website

[Visit PixelForge Studio](https://afsanaislam789.github.io/pixel-forge/)

## 📌 About The Project

PixelForge Studio is a front-end web development project. This website showcases different digital services through a clean and modern design.

The website is created using HTML and CSS.

## ✨ Features

- Modern Navigation Bar
- Attractive Hero Section with Background Image
- Responsive Service Card Layout
- Six Different Service Categories
- Interactive Hover Effects
- Contact Button with Popup Section
- Footer with Quick Links
- Contact Information Section
- Social Media Section

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Planned for future functionality)
